# My Little Randomizer

A simple Python project that randomizes wild Pokémon encounters in Pokémon FireRed (USA v1.0).

## Features
- Randomizes wild Pokémon encounters.
- Preserves Pokémon levels and encounter rates.
- Creates a separate randomized ROM.

## Playthrough
- **Starter:** Squirtle
- **Caught:** Girafarig

## Development
Built from scratch using Python and PowerShell on Windows. The project involved inspecting the ROM, finding encounter tables, debugging scripts, and testing the randomizer.

## Requirements
- Python 3
- Pokémon FireRed USA v1.0 ROM
- mGBA
